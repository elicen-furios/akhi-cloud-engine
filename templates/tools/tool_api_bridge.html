How to Use This Tool — Documentation & Features

Step-by-Step Instructions

  1. Enter a complete public URL starting with http:// or https:// in the input field.
  2. Click the Extract JSON button to initiate a real-time request from the backend engine.
  3. Review the structured JSON payload or parsed DOM headings and links in the Live Execution Output terminal.
  4. Click Copy Output at the top-right of the terminal to copy the JSON data for your project.

Key Capabilities & Features

  • Automatic JSON Detection: Directly parses native REST API responses when available.
  • DOM Fallback Scraper: Extracts page titles, H1/H2 headers, and external links from standard HTML pages.
  • SSRF Protection: Automatically blocks internal loopback and local network addresses for cloud security.
