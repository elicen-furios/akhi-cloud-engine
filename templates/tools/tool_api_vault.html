How to Use This Tool — Documentation & Features

Step-by-Step Instructions

  1. Paste any API token, JWT secret, or bearer key into the input box.
  2. Click Audit Secret to run a mathematical entropy and character analysis.
  3. Check the rating (High, Medium, or Weak) and shannon_entropy_score in the output box.

Key Capabilities & Features

  • Shannon Entropy Calculation: Measures true randomness and unpredictability per character.
  • Character Diversity Check: Verifies presence of uppercase, lowercase, digits, and special symbols.
  • Zero Data Retention: Keys are analyzed in-memory and never logged or stored on disk.
