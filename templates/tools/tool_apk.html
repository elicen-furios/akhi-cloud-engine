How to Use This Tool — Documentation & Features

Step-by-Step Instructions

  1. Tap Choose File and select any valid .apk package from your device storage.
  2. Click Inspect APK Archive to upload and analyze the package structure in memory.
  3. Review the total file count, classes.dex count, AndroidManifest.xml status, and native lib/ components.

Key Capabilities & Features

  • Zero-Execution Static Analysis: Safely inspects internal archive headers using Python's zipfile engine without running untrusted code.
  • DEX & Architecture Discovery: Counts multi-dex bytecode files and identifies compiled native C/C++ libraries.
